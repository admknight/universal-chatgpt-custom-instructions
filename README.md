# Universal ChatGPT Custom Instructions

**Copy once. Paste once. Use ChatGPT normally.**

Ready-to-paste adaptive ChatGPT Custom Instructions for Free, Go, Plus, Pro, Business, Enterprise and Education users. There is no module selection, builder, setup workflow or manual activation step.

## Where to paste

**Web / Desktop:** Settings -> Personalization -> Custom Instructions.

**iOS / Android:** Settings -> Customize ChatGPT -> Custom Instructions.

After saving, chat normally. The instruction set automatically adapts to everyday questions, writing, learning, research, professional/trade work, technical work, files, calculations, code, AI/prompt work, images, reference-identity consistency, video/multimedia continuity and high-consequence topics.

Custom Instructions guide behavior; they do not unlock capabilities unavailable to the user's account, model, device, region or workspace.

## Attribution design

The runtime files use a compact attribution line to preserve Custom Instructions space:

`© 2026 Zahid Hussain / Scopewise Consulting | UPA R6`

Full authorship, copyright and licensing information stays in the repository metadata/license rather than consuming the runtime character budget.

## Design principles

The runtime instructions prioritize five ideas: **Adapt, Ground, Preserve, Verify, Economize.** They are compressed so the character budget is spent on useful behavior rather than ceremonial formatting.

## Validation status

The files pass structural checks for character limits, compact attribution, required repository structure, repository separation and JSON metadata. Live behavior has not been empirically validated in every ChatGPT account/UI combination, so this release is not described as universally runtime-proven.
