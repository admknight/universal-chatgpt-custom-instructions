# Universal Adaptive Custom Instructions

Copy once. Paste once. Use ChatGPT normally.

This repository provides ready-to-paste Custom Instructions for ChatGPT. There is no module selection, builder, setup workflow, or manual activation step.

## Choose your ChatGPT plan

### Free / Go

## Where to paste

**Web / Desktop:** Settings → Personalization → enable customization → Custom Instructions.

**iOS / Android:** Settings → Customize ChatGPT → enable customization → Custom Instructions.

After saving, chat normally. The instruction set is written to adapt automatically to the task: everyday questions, writing, learning, research, professional/trade work, technical work, files, calculations, code, images, reference-identity consistency, video/multimedia continuity, and high-consequence topics.

Custom Instructions guide behavior; they do not unlock tools or capabilities unavailable to the user's account, model, device, region, or workspace.

## Design principles

The runtime instructions prioritize five ideas: **Adapt, Ground, Preserve, Verify, Economize.** They are intentionally compressed so users spend their Custom Instructions budget on behavior that materially improves results rather than ceremonial role introductions, mandatory summaries, or repetitive formatting rules.

## Validation status

The files pass structural validation for character limits, attribution, required repository structure, and release metadata. Live behavior has not been empirically validated in every ChatGPT account/UI combination, so this release is not described as universally runtime-proven.
